# Dashboard de Analítica en Salud

Proyecto creado desde cero para publicar en GitHub Pages.

## Archivos
- `index.html`: página principal.
- `styles.css`: diseño visual.
- `script.js`: lógica del dashboard.
- `data/datos.csv`: datos de ejemplo.
- `assets/`: carpeta para logos o imágenes.

## Indicadores incluidos
- Total de atenciones.
- Meta acumulada.
- Cumplimiento porcentual.
- Brecha.
- Errores.
- Estado global.
- Tendencia mensual.
- Producción por servicio.
- Cumplimiento por establecimiento.
- Alertas inteligentes.
- Tabla de detalle.

## Publicar en GitHub Pages
1. Crear repositorio en GitHub.
2. Subir todos los archivos descomprimidos.
3. Ir a `Settings`.
4. Entrar a `Pages`.
5. Elegir `Deploy from a branch`.
6. Seleccionar `main` y `/root`.
7. Guardar.

## Datos reales
Para usar datos reales, reemplaza `data/datos.csv`.

Respeta estas columnas:

`fecha,mes,establecimiento,servicio,profesional,atenciones,meta,errores`
